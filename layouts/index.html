📜 The SQL Linter for humans

SQLFluff is an open source, dialect-flexible and configurable SQL linter. Designed with ELT applications in mind, SQLFluff also works with Jinja templating and dbt. SQLFluff will auto-fix most linting errors, allowing you to focus your time on what matters.

One tool for consistent SQL

Find style and syntax issues early, apply safe fixes, and adapt the rules to the way your team works.

Lint

Report SQL issues automatically so code reviews can focus on function rather than form.

Fix

Correct many linting issues automatically and keep SQL consistent and legible.

Parse

Catch syntax issues without database access, before code reaches later development stages.

Configure

Start with opinionated defaults, then tailor dialects, rules, and formatting to local needs.

Getting started

Install SQLFluff from PyPI, then lint a file using your chosen SQL dialect.

Continue with the installation guide
Terminal
$ pip install sqlfluff
$ echo "  SELECT a  +  b FROM tbl;  " > test.sql
$ sqlfluff lint test.sql --dialect ansi
== [test.sql] FAIL
L:   1 | P:   1 | LT01 | Expected only single space before 'SELECT' keyword.
L:   1 | P:   1 | LT02 | First line should not be indented.
L:   1 | P:  11 | LT01 | Expected only single space before binary operator '+'.
L:   1 | P:  27 | LT12 | Files must end with a single trailing newline.
All Finished!
